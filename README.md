## 🚀 Projects

### React projects

Each project is a small, beginner-friendly React app built with Vite. Open a folder to see its own README with features and how to run it.

| Project | What it does |
| --- | --- |
| [DecisionDesk](./decision-desk) | Helps you decide between options, with weights and a random pick |
| [SkillTrack](./skill-track) | Tracks skills you are learning with progress bars |
| [SpendWise](./spend-wise) | Splits shared expenses between friends and shows who owes whom |
| [FocusFlow](./focus-flow) | Pomodoro timer with a task list |
| [BudgetBuddy](./budget-buddy) | Monthly budgets per category with spending tracking |
| [QuizForge](./quiz-forge) | Make your own quizzes, take them, and review your score |

To run any project:

```bash
cd <project-folder>
npm install
npm run dev
```
